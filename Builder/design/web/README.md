# Craft Builder — дизайн без Claude

Статическая версия макетов: чистые HTML/CSS/JS, без фреймворков и без артефакта.

## Как открыть

- Двойной клик по `index.html` (работает с `file://`), или
- `npx serve .` в этой папке и открыть показанный адрес.

В просмотрщике: колесо мыши — зум, перетаскивание — перемещение, меню слева — переход к экрану,
клавиши `0` / `+` / `−`. Клик по ссылке внутри экрана (например, карандаш в профиле) переносит к нужной
доске. Название доски — ссылка, открывающая экран отдельно (`screens/S50.html`).
Лист **User flow** — `flow.html`: стрелки показывают, откуда и куда попадает пользователь.

Шрифты (Onest, JetBrains Mono) подтягиваются с Google Fonts; без интернета будет системный шрифт.

## Как это устроено

- `../*.dc.html` и `../canvas.json` — **исходники** дизайна (формат Claude Design). Редактируются там.
- `build.mjs` — Node-скрипт (без зависимостей): убирает служебные теги, чинит ссылки, подставляет
  значения шаблонов, заменяет миниатюры Flow живыми экранами и пишет `boards.js` из `canvas.json`.
- `screens/`, `flow.html`, `boards.js` — **результат сборки**, лежат в git, чтобы открывалось сразу.
- `index.html`, `viewer.js`, `viewer.css` — просмотрщик (≈150 строк JS).

После правки исходников:

```bash
node build.mjs
```

Экраны — обычная вёрстка 390×844 (`.scr`), стили инлайновые и в `<style>` страницы; токены
(цвета, радиусы, шрифты) описаны в `../../docs/craft-builder-design-brief.md` и на досках UI-кита.
