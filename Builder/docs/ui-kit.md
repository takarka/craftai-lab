# UI Kit · Flutter

UI Kit реализован в самостоятельном приложении `Builder`. Точка входа `lib/main.dart` открывает интерактивный каталог. Каталог не является готовым приложением ассистента: ответы, уроки и календарь — демонстрационные данные.

## Источники

- `design/UK1.dc.html` — точные цвета, типографика, отступы, радиусы, тени, 24 контурные иконки.
- `design/UK2.dc.html` — кнопки, чипы, поля, прогресс, переключатели и выбор.
- `design/UK3.dc.html` — шапки, нижняя навигация, сообщения и карточки.
- `design/UK4.dc.html`, `design/Char.dc.html` — векторный персонаж, модули уровней 0–5 и компактная форма.
- `docs/craft-builder-design-brief.md`, `docs/user-flow.md` — доступность, состояния данных и последние решения аудита.

Документация и дизайн поступили из ветки `docs/builder-docs-and-design`; на момент начала работы в `main` их не было. Источники сохранены вместе с реализацией, а HTML-макеты не переписывались.

## Использование

```dart
import 'package:builder/ui_kit/ui_kit.dart';

MaterialApp(theme: BuilderTheme.light, home: YourScreen());

BuilderButton(label: 'Продолжить', onPressed: continueLesson);
BuilderDataChip(DataLocation.cloud);
BuilderCharacter(level: 4, mood: CharacterMood.thinking);
```

Все части экспортируются из `lib/ui_kit/ui_kit.dart`.

| Файл | API |
|---|---|
| `tokens.dart` | `BuilderColors`, `BuilderType`, `BuilderSpace`, `BuilderRadii`, `BuilderShadows` |
| `theme.dart` | `BuilderTheme.light`: Material 3, поля, шторки, типографика, уведомления |
| `identity.dart` | `BuilderGlyph` / `BuilderIcon`, `BuilderCharacter`, `CharacterMood` |
| `controls.dart` | `BuilderButton`, `BuilderIconButton`, `BuilderBadge`, `BuilderDataChip`, `BuilderField`, `BuilderSegments`, `BuilderProgress`, `BuilderToggleRow`, `BuilderComposer`, `showBuilderSheet` |
| `compositions.dart` | `BuilderCard`, `BuilderIconTile`, `BuilderNotice`, `BuilderEmptyState`, `BuilderLessonCard`, `BuilderSkillCard`, `BuilderModelCard`, `BuilderLinkRow`, `BuilderAssistantHeader`, `BuilderBottomNavigation`, `BuilderMessage`, `BuilderActionCard`, `BuilderSkeleton` |
| `gallery/catalog.dart` | Каталог примеров с интерактивными контролами |

## Состояния и поведение

- Кнопки: основная, вторичная, опасная, опасная с заливкой, текстовая; нажатие, загрузка, отключено. При загрузке действие заблокировано.
- Чипы: четыре места обработки данных. Чип открывает пояснение, режим сервера в Казахстане обозначен как будущий. Вариант компактного облачного чипа — «Данные за рубежом».
- Поля: подпись, подсказка, ошибка, отключено, многострочный ввод. В каталоге почта проверяется при вводе.
- Сообщение: готово, генерация, остановлено, ошибка с повтором; раскрываемые источники, копирование, callback для слоя «Под капотом».
- Слой «Под капотом»: `showBuilderSheet` и пример трёх вкладок «Схема / Рентген / Аналогия» по последнему `user-flow.md`, а не раннему требованию о четырёх вкладках.
- Действие: только явное подтверждение запускает переданный async callback. Повторное нажатие во время выполнения исключено. Сохраняются результат, отмена либо ошибка с возможностью повторить. В галерее callback демонстрационный и календарь не изменяет.
- Уровень: пройден, текущий, закрыт, скоро. Умение: включено, выключено, закрыто, недоступно, скоро.
- Системные состояния: загрузка-скелетон, пусто, ошибка с действием, офлайн, предупреждение, уведомление.
- Персонаж: исходный SVG из макета, уровень 0–5, набор выключенных модулей, компактный вариант. Неоткрытые модули видны на 14% по UK4; выключенные открытые — на 35%. Семь состояний обозначены подписью и иконкой. Это статические состояния; анимация Lottie, голос и работа инструментов сюда не входят.

## Решения по доступности

- Основной текст 16/23: требование доступности в ТЗ имеет приоритет над 15/21 в UK1. Остальные ступени шкалы сохранены.
- Нажатия от 44 px, кнопки от 48 px; подписи и чипы переносятся, текстовый масштаб не ограничивается.
- У иконочных кнопок есть tooltip и доступное имя. Выбор, прогресс, персонаж и состояния снабжены семантикой.
- Статусы сопровождаются текстом и иконкой. Цвет успеха — фирменный синий, зелёный не добавлялся.
- Включён системный масштаб текста; при `disableAnimations` индикатор загрузки статичен. Анимаций персонажа нет, поэтому все его состояния доступны при уменьшенном движении.
- Onest и JetBrains Mono встроены локально с лицензиями OFL. Шрифты не требуют Google Fonts во время работы. Onest содержит казахские буквы; полный перевод приложения на казахский — отдельная задача.

## Запуск и проверка

```sh
cd Builder
flutter pub get
flutter analyze
flutter test
flutter build web --release
flutter run -d chrome
```

Каталог поддерживает стартовые ссылки `?section=foundations`, `?section=controls`, `?section=compositions`, `?section=character`.

Тесты проверяют все четыре раздела на 360×780, 390×844, 430×932 при масштабе текста 130%, а также на desktop 1440×1000; пояснение чипа; отправку непустого текста; защиту действия от повторов, ошибку/повтор/отмену; навигацию и выбор уровня персонажа.
