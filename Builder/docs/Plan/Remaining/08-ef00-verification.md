# EF-00 — сверка реализации

19.10.2026. Текущий статус и коммит фиксируются в [progress.md](progress.md). Этот документ связывает объём EF-00 с кодом и проверками; native-приёмку не заменяет.

| Требование | Реализация и доказательства |
|---|---|
| Сверить основу, не переписывая подсистемы | Каталог и оба репозитория используют прежние ключи хранения. `AssistantSkillId` не переиспользован для сценариев Skills. Подключены существующие чат, версии и trace. |
| Смысловые ID отдельно от номера | `CourseTopic`: `contentId`, `storageId`, `displayOrder`; каталог RU/KK содержит 11 тем. `course_curriculum_upgrade_test`, `course_display_progress_test`. |
| Сохранить прогресс 9 → 11 | Чтение по прежним ключам не переписывает строки. Повторное открытие сохраняет достижения всех девяти тем, попытки и версии контента; новые темы 10/11 не завершаются автоматически. `course_curriculum_upgrade_test`. |
| Политика доступа | D-13, `CourseAccess`, `LessonAccessGate`; карта и прямые ссылки используют одну политику. `course_access_policy_test`, `lesson_access_gate_test`. |
| Каталог, переходы, проценты | Порядок 1–11; шесть реализованных тем входят в активный прогресс. Неподдерживаемые темы обозначены как недоступные. Переходы опираются на смысловые темы, а не `id + 1`. `course_engine_and_lesson_flow_test`, `course_curriculum_upgrade_test`. |
| Персонаж, награды, номера RU/KK | SVG имеет 11 независимых модулей; завершение одной темы не включает другую. Номер в настройках, словаре, учебных экранах, сообщении версии и итогах берётся из порядка отображения. Итог урока использует персонажа курса. `course_character_test`, `profile_test`, `assistant_settings_and_versions_test`, `course_engine_and_lesson_flow_test`. Иллюстрации будущих функций остаются C-04. |
| Мини-проверки и trace | Урок Skills RU/KK содержит три вопроса; практика подтверждается двумя завершёнными запусками с исправлением навыка между ними. Все три вкладки trace показывают один отправленный сценарий и входы. `skill_practice_evidence_test`, `skills_trace_test`, `content_validator_test`. |
| Версии, удаление и сброс | Skills включены в версии; восстановление не выдаёт новых разрешений. Сброс и удаление владельца удаляют сценарии, сохраняя другого владельца. Совместимое добавление таблиц и сброс прогресса транзакционны. Сбой удаления попыток откатывает удаление прогресса. `skills_and_versions_test`, `persistent_storage_test`, `course_curriculum_upgrade_test`. |
| Исключить звонки/SMS (D-06) | `prepare_call` отсутствует в реестре и схемах модели; нет группы связи и предложения звонков. Старые карточки скрыты и не исполняются даже со старым разрешением. `tools_and_level_5_test`. Константа и изолированный адаптер сохранены для исторических записей/тестов, production-диспетчер адаптер не подключает. |

`integration_test/ef00_upgrade_test.dart` проверяет на native SQLite повторное открытие старого прогресса, добавление Skills, версии, персонажа RU/KK, сброс и удаление с изоляцией владельцев. Для теста создаётся отдельная временная база; реальная база приложения не читается и не изменяется. Команда: `flutter test integration_test/ef00_upgrade_test.dart -d <device-id> --no-pub`.

Владелец уточнил: ручная проверка была частичной на Android; iOS не проверялся. Результат автоматического Android-прогона и оставшиеся ограничения записываются в progress.md. Отсутствие проверки iOS не позволяет объявить всю приёмку EF-00 завершённой.
