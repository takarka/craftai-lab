# Этапы Backend

[Общий план и требования](../flutter-implementation-plan.md) · [Другой контур](../Flutter/README.md)

10 отдельных этапов. Владелец — команда backend CraftAI. Телефонные действия, локальные документы/индекс/версии и курс не становятся серверными задачами. Сервер может реализовываться параллельно Flutter по B00.

| Этап | Результат |
|---|---|
| [B00](B00.md) | Контракты и аудит существующего CraftAI |
| [B01](B01.md) | Идентификация, сессии и восстановление |
| [B02](B02.md) | Каталог моделей и серверная конфигурация |
| [B03](B03.md) | Генерация, streaming и продолжение инструментов |
| [B04](B04.md) | Серверный веб-поиск |
| [B05](B05.md) | Демонстрационный MCP и каталог уроков |
| [B06](B06.md) | Учёт использования аккаунта |
| [B07](B07.md) | Профиль, жалобы и жизненный цикл аккаунта |
| [B08](B08.md) | Серверная безопасность и наблюдаемость |
| [B09](B09.md) | Backend CI, staging и серверный выпуск |

Номер задаёт логический порядок, а не календарный спринт. Независимые этапы допустимо выполнять параллельно после выполнения их входных зависимостей. Чекбоксы пока открыты: это план предстоящей реализации.
