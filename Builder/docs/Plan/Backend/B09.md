# B09. Backend CI, staging и серверный выпуск

[Все этапы backend](README.md) · [Общий план](../flutter-implementation-plan.md)

**Контур:** только сервер CraftAI, его контракты, данные, интеграции, тесты и deployment.

**Зависимости:** B01–B08.

**Граница:** не изменять Flutter UI, native-плагины, локальную БД телефона, курс/прогресс или мобильный CI. Готовность клиента не блокирует серверные contract tests. Стек выбирать по аудиту B00 существующего CraftAI.

## Задачи

- [ ] B09-01. Создать отдельный backend pipeline для schema/contract/unit/integration/security checks; Flutter signing и APK/IPA не входят в этап.
- [ ] B09-02. Подготовить dev/staging/prod с разделёнными secrets, тестовыми аккаунтами, TLS и версиями API.
- [ ] B09-03. Собирать и развёртывать backend артефакт воспроизводимо, выполнять миграции только серверных данных с backup/rollback стратегией.
- [ ] B09-04. Проверить streaming через production reverse proxy, timeout/cancellation, readiness/liveness и upstream degradation.
- [ ] B09-05. Провести серверный load/abuse smoke test с согласованными порогами; не придумывать SLA/нагрузку из дизайна.
- [ ] B09-06. Опубликовать доступные URL, версии контрактов, release notes, fixtures и результаты BT00–BT08 как вход для F19/F20.
- [ ] B09-07. Отрепетировать rollback server/config, совместимость с предыдущей мобильной версией и incident response.
- [ ] B09-08. Выпустить серверную версию отдельно; не объявлять мобильный MVP принятым только по здоровью backend.

## Результат

Развёрнутое и проверенное окружение CraftAI, server release checklist.

## Проверки и критерий выхода

BT09: clean deploy/health/streaming через proxy/rollback/совместимость API и полный набор BT00–BT08; mobile release остаётся F19.

Все обязательные задачи выполнены, контракт и примеры опубликованы, серверные отрицательные сценарии пройдены. Наличие макета или клиентской заглушки не подтверждает готовность backend.
