# B05. Демонстрационный MCP и каталог уроков

[Все этапы backend](README.md) · [Общий план](../flutter-implementation-plan.md)

**Контур:** только сервер CraftAI, его контракты, данные, интеграции, тесты и deployment.

**Зависимости:** B00/B01/B03; согласованный обезличенный каталог.

**Граница:** не изменять Flutter UI, native-плагины, локальную БД телефона, курс/прогресс или мобильный CI. Готовность клиента не блокирует серверные contract tests. Стек выбирать по аудиту B00 существующего CraftAI.

## Задачи

- [ ] B05-01. Развернуть один разрешённый демонстрационный MCP-коннектор CraftAI; произвольные адреса/marketplace исключены из MVP.
- [ ] B05-02. Опубликовать server info, tools/list и schemas; подтвердить имена search_lessons/get_lesson либо вернуть утверждённый эквивалент.
- [ ] B05-03. Подготовить обезличенные уроки и реальные read-only операции поиска/получения; не использовать данные учеников.
- [ ] B05-04. Валидировать tool name/arguments, размер и тип ответа, scopes и session; ограничить время/число вызовов.
- [ ] B05-05. Возвращать реальные execution status/source/duration и разделять auth/transport/tool/domain errors.
- [ ] B05-06. Реализовать отмену/отзыв доступа в доступных границах; повтор не создаёт неизвестных побочных эффектов.
- [ ] B05-07. Не сохранять заметку на телефоне серверной MCP-командой: локальное сохранение результата — действие F15.

## Результат

Действующий demo MCP gateway, каталог и валидируемые schemas.

## Проверки и критерий выхода

BT05: tools/list/call, неизвестный tool, invalid schema, empty catalog, timeout, revoked session и запрет произвольного внешнего URL.

Все обязательные задачи выполнены, контракт и примеры опубликованы, серверные отрицательные сценарии пройдены. Наличие макета или клиентской заглушки не подтверждает готовность backend.
