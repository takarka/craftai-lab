# F14. Уровень 5 — инструменты на телефоне и клиент поиска

[Все этапы Flutter](README.md) · [Общий план](../flutter-implementation-plan.md)

**Контур:** только Flutter, локальные данные, native-адаптеры, клиентские тесты и мобильная поставка.

**Внешний вход backend:** B04 для поиска; календарь/заметки/звонок выполняются клиентом. Получение готового API/отчёта не является серверной работой этого этапа.

**Граница:** здесь не создавать серверные endpoints, БД, gateway, provider config или backend deployment. Если API не готов, использовать явно обозначенные contract fixtures для разработки; живую приёмку оставить заблокированной. Упоминания разделов/ADR/T-сценариев относятся к общему плану.

**Зависимость:** F01/F07/F08/F09/F10; contracts и политика подтверждения утверждены.

- [x] F14-01. Реализовать общий registry tools, schema validation, capabilities и runtime dispatcher.
- [x] F14-02. Собрать S43 с тремя группами; grant, OS permission и временная доступность отображаются отдельно.
- [x] F14-03. Добавить read-calendar и create-event; выбор календаря, timezone, интервалы, all-day и отсутствие разрешения.
- [x] F14-04. Показывать D07 до OS prompt; проверять изменение permission при возврате из настроек.
- [x] F14-05. Для записи использовать доменную confirmation state machine, а не кнопочный callback без сохранённого согласия.
- [x] F14-06. Добавить локальные заметки/файлы ассистента: create/read/search/delete в приватной области, с безопасными именами и ограничениями размера.
- [x] F14-07. Реализовать подготовку звонка/сообщения, минимальный выбор контакта или ручной номер, preview и открытие системного окна.
- [x] F14-08. Не запрашивать SMS inbox/call log permission, не отправлять сообщения автоматически, не заявлять факт звонка по открытию dialer.

- [x] F14-10. Передавать модели только разрешённые schemas; проверять доступ ещё раз перед реальным исполнением.

- [x] F14-12. Обработать double tap, повтор tool-call, истечение карточки, change parameters, revoke, app restart и неизвестный результат.

**Приёмка:** тест доказывает отсутствие записи без согласия; повторное событие не создаётся после сетевой/локальной неопределённости; отключённый инструмент не исполняется даже по старому tool-call.
