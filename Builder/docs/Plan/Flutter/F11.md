# F11. Уровень 2 — инструкции

[Все этапы Flutter](README.md) · [Общий план](../flutter-implementation-plan.md)

**Контур:** только Flutter, локальные данные, native-адаптеры, клиентские тесты и мобильная поставка.

**Внешний вход backend:** B03 для реальной учебной проверки. Получение готового API/отчёта не является серверной работой этого этапа.

**Граница:** здесь не создавать серверные endpoints, БД, gateway, provider config или backend deployment. Если API не готов, использовать явно обозначенные contract fixtures для разработки; живую приёмку оставить заблокированной. Упоминания разделов/ADR/T-сценариев относятся к общему плану.

**Зависимость:** F07/F09/F10; базовый уровень 1 уже использует реальный диалог.

- [x] F11-02. Детерминированно собирать итоговую instruction из включённых правил в фиксированном порядке.
- [x] F11-03. Показать читаемое превью, оценку токенов и лимит; объяснить, что правило не гарантирует точность ответа.

- [x] F11-05. Разделить raw mode и structured rules, чтобы сохранение не затирало ручной текст обратной генерацией.
