# F12. Уровень 3 — знания и локальный RAG

[Все этапы Flutter](README.md) · [Общий план](../flutter-implementation-plan.md)

**Контур:** только Flutter, локальные данные, native-адаптеры, клиентские тесты и мобильная поставка.

**Внешний вход backend:** B03 для ответа по локально найденным фрагментам; сервер не индексирует документы. Получение готового API/отчёта не является серверной работой этого этапа.

**Граница:** здесь не создавать серверные endpoints, БД, gateway, provider config или backend deployment. Если API не готов, использовать явно обозначенные contract fixtures для разработки; живую приёмку оставить заблокированной. Упоминания разделов/ADR/T-сценариев относятся к общему плану.

**Зависимость:** F01/F03/F07/F08/F09/F10; ADR-02/07/08 закрыты.

- [ ] F12-01. Реализовать выбор файла с D03 до импорта; проверить размер, фактический формат, доступное место и ограничения администратора.
- [ ] F12-02. Скопировать файл в приватное пространство; безопасно нормализовать имя, не использовать пользовательский путь как внутренний ID.
- [ ] F12-03. Извлекать текст PDF/DOCX/TXT вне UI isolate; обрабатывать пароль, скан без текста, повреждение, неизвестную кодировку, пустой результат.
- [ ] F12-04. Для DOCX ограничить распаковку и обработку; не исполнять макросы/активное содержимое и внешние ссылки.
- [ ] F12-05. Сделать стабильный chunking с метаданными страницы/раздела и версией алгоритма.
- [ ] F12-06. Вычислять embeddings на устройстве и хранить индекс локально; считать индексацию отдельной отменяемой задачей.
- [ ] F12-07. Сделать поиск, ranking, порог релевантности и явный результат «ничего не найдено».
- [ ] F12-08. Реализовать «Проверить поиск» с фрагментами, источниками и отдельным запуском ответа.
- [ ] F12-09. В запрос отправлять только выбранные chunks; показать это в trace, не помечать весь ответ как обработанный «на телефоне».
- [ ] F12-10. Источники ответа сверять с реально предоставленными chunks; произвольную ссылку, выданную моделью, не считать доказанным источником.
- [ ] F12-11. Исключать выключенные/удалённые документы из новых запросов и остановить устаревшие indexing jobs по revision/epoch.
- [ ] F12-12. Реализовать полное удаление производных данных и последствия для versions/traces по ADR-02.
- [ ] F12-13. Поддержать безопасное возобновление индексации после рестарта и перестроение при изменении embedding model.
- [ ] F12-14. Подготовить два задания уровня 3: ответ есть в документе и ответа нет; объяснить риск выдумки, не гарантируя автоматическое обнаружение лжи.

**Приёмка:** PDF/DOCX/TXT из тестового набора дают воспроизводимый поиск RU/KK; off/delete исключает ресурс; полный документ не уходит в сеть; UI отзывчив при обработке; отсутствие релевантного фрагмента обозначено честно.

- [ ] F12-V01. S41: раздельно показать локальный документ и отправляемые в облако фрагменты. Файл XLSX в D03 заменить примером PDF/DOCX/TXT; XLSX parser не добавлять в MVP.
