# F17. Подготовить и связать весь контент RU/KK

[Все этапы Flutter](README.md) · [Общий план](../flutter-implementation-plan.md)

**Контур:** только Flutter, локальные данные, native-адаптеры, клиентские тесты и мобильная поставка.

**Внешний вход backend:** B02/B03: доступные модели для проверки RU/KK, без изменения их серверной конфигурации. Получение готового API/отчёта не является серверной работой этого этапа.

**Граница:** здесь не создавать серверные endpoints, БД, gateway, provider config или backend deployment. Если API не готов, использовать явно обозначенные contract fixtures для разработки; живую приёмку оставить заблокированной. Упоминания разделов/ADR/T-сценариев относятся к общему плану.

**Зависимость:** F10 и тексты/практики F11–F15; работу редактора начинать раньше параллельно контрактам.

- [ ] F17-01. Утвердить schema курса, глоссария, FAQ и аналогий с versioned IDs.
- [ ] F17-02. Подготовить пять полных уровней: цель, идея, практика, под капотом, 3–5 вопросов, итог и необязательная рефлексия.
- [ ] F17-03. Убрать из MVP оставшиеся задания сравнения моделей, голос/фото/агент и обещание сертификата.
- [ ] F17-04. Подготовить согласованные свидетельства зачёта и пороги; не зашивать их в виджеты.
- [ ] F17-05. Подготовить sample-документы без ученических данных и корректные пары hit/miss для RAG.
- [ ] F17-06. Перевести UI и редакторский контент на казахский, выполнить предметную и языковую проверку носителем.
- [ ] F17-07. Проверить строки, plural, даты/время, орфографию терминов и отсутствие смешения locale `kk` с обозначением страны `KZ`.
- [ ] F17-08. Настроить validation контента: missing translations/IDs/links/evidence, неправильный threshold, недостижимый шаг.
- [ ] F17-09. Bundle первых пяти уровней включить в приложение для offline-теории; обновления контента совместимы и не ломают текущий lesson checkpoint.
- [ ] F17-10. Пройти весь курс вручную на RU и KK, включая долгие строки и смешанный язык ответов модели.

**Приёмка:** все MVP-экраны и пять уроков полностью доступны на обоих языках; аналогии не расходятся между trace и уроком; редакторский контент не требует произвольного исполняемого кода с сервера.
