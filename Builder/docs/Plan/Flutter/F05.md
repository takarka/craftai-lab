# F05. Реализовать оболочку, онбординг и первое согласие

[Все этапы Flutter](README.md) · [Общий план](../flutter-implementation-plan.md)

**Контур:** только Flutter, локальные данные, native-адаптеры, клиентские тесты и мобильная поставка.

**Внешний вход backend:** B01; согласованные тексты передачи данных B08. Получение готового API/отчёта не является серверной работой этого этапа.

**Граница:** здесь не создавать серверные endpoints, БД, gateway, provider config или backend deployment. Если API не готов, использовать явно обозначенные contract fixtures для разработки; живую приёмку оставить заблокированной. Упоминания разделов/ADR/T-сценариев относятся к общему плану.

**Зависимость:** F04.

- [x] F05-01. Собрать S01–S03 из production UI Kit: тезисы, предмет, классы, языки и имя.
- [x] F05-02. Предзаполнять только доступные поля аккаунта; сохранять локальный draft между шагами.
- [x] F05-03. Поддержать поиск предмета, «Другое», мультивыбор 1–11 и живую сводку.
- [x] F05-04. Создавать базовый workspace/ассистента однократно; повторный тап «Начать» не дублирует записи.
- [x] F05-05. Встроить D02 перед первым облачным запросом; сохранить policy version и дату acknowledgment.
- [x] F05-06. Отсрочку D02 вести в локальную часть, с повторным запросом согласия при попытке отправки.
- [x] F05-07. Установить «Ассистент» вкладкой по умолчанию; сохранить независимые стеки Курс/Профиль.
- [x] F05-08. После повторного входа не запускать весь онбординг, если он завершён в том же локальном пространстве.

**Приёмка:** маршрут S00 → S01 → S02 → S03 → D02 → S10 проходит без тупиков; нет скрытой передачи предмета/класса в базовую модель до согласованного включения инструкций.

- [x] F05-V01. Реализовать отсутствующие в S00 экраны регистрации/восстановления и выбор языка ассистента. Группы классов S02 переводить в явные множества классов; модель данных хранит 1–11.

- [x] F05-V02. D02 открывать поверх вызвавшего экрана онбординга; фон S33 в прототипе не задаёт обязательный переход. Начальный персонаж без модулей не означает нулевой учебный уровень.
