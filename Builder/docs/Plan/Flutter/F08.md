# F08. Реализовать настоящую трассу и «Под капотом»

[Все этапы Flutter](README.md) · [Общий план](../flutter-implementation-plan.md)

**Контур:** только Flutter, локальные данные, native-адаптеры, клиентские тесты и мобильная поставка.

**Внешний вход backend:** B03/B06: фактические metadata/usage. Получение готового API/отчёта не является серверной работой этого этапа.

**Граница:** здесь не создавать серверные endpoints, БД, gateway, provider config или backend deployment. Если API не готов, использовать явно обозначенные contract fixtures для разработки; живую приёмку оставить заблокированной. Упоминания разделов/ADR/T-сценариев относятся к общему плану.

**Зависимость:** F07. Для следующих уровней trace расширяется вместе с соответствующим domain adapter.

- [x] F08-01. Ввести типизированные события этапов и immutable итоговый trace, привязанный к одному request ID.
- [x] F08-02. Хранить фактически отправленные слои, результаты retrieval, tool schemas, параметры, результаты и usage.
- [x] F08-03. Создать S31 с тремя вкладками и сохранением выбранного ответа при переключении.
- [x] F08-04. Построить схему пути запроса с местом каждого шага, реальными длительностями и честно отсутствующими значениями.
- [x] F08-05. В рентгене показать роли и слои; число токенов разделять на server-reported и оценённое клиентом.
- [x] F08-06. В аналогии использовать редакторский RU/KK-контент уровня, не генерировать учебную истину случайной моделью.
- [x] F08-07. Подключить термины к S27 и проверенный возврат к исходному сообщению/уроку.
- [x] F08-08. Отдельно отображать aborted/error/partial trace и отсутствие исторических данных после удаления.
- [x] F08-09. Демо-трассы из bundle явно помечать «пример»; production UI не выдаёт их за реальный запрос.
- [x] F08-10. Не показывать скрытые внутренние рассуждения модели как «рентген»: доступны наблюдаемые сообщения, контекст, вызовы и результаты, а не выдуманная цепочка мыслей.

**Приёмка:** проверка сериализованного payload и рентгена подтверждает одинаковый контекст; схема, рентген и аналогия относятся к одному событию. S24 использует тот же компонент с учебным акцентом.

- [x] F08-V01. S31/S31b/S31c реализовать состояниями одного overlay: схема из пяти шагов, X-ray, аналогия. Все представления читают одну трассу; числа 748 токенов/4,6 с — только fixtures.
