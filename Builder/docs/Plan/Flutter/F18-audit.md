# F18. Начальный аудит данных и offline

Статус: статический аудит исходников от 18 октября 2026. Это не проверка устройства, платформенного backup или backend/APM; B08 и физические устройства не предоставлены.

## Карта локальных данных

| Хранилище | Данные | Наблюдение / проверка F18 |
|---|---|---|

## Диагностика и платформенные декларации

- В Dart-коде не найдено прямых вызовов `print`, `debugPrint`, `developer.log`, Crashlytics или Sentry. Это статический поиск, не доказательство отсутствия логов во внешнем native/plugin слое.
- `StorageDatabase` сохраняет исходную причину ошибки как `cause`; некоторые исключения secure storage включают строку исходной ошибки. Провести review того, что может попасть в UI/crash reporter при production-сборке.
- Android manifest не задаёт `android:allowBackup` или правила исключения данных. В iOS `Info.plist` не содержит декларации исключения файлов из backup. Политику backup пока нельзя считать зафиксированной.
- В `android/app/src/main/AndroidManifest.xml` и iOS `Info.plist` не обнаружены специальные разрешения для доступа к контактам/геолокации/камере. Это не заменяет проверку фактических permission prompts и собранных plugin manifest.

## Блокеры сценариев

- Без B08 нельзя сопоставить отображаемую карту с серверными логами/APM и маршрутом передачи данных провайдерам.
- Без подписанных iOS/Android сборок и физических устройств нельзя закрыть reinstall, backup restore, системные разрешения, VoiceOver/TalkBack, keyboard/safe areas и native file protection.
- Ошибка удаления файла теперь оставляет DB-записи для повтора, отключает документ от новых запросов и возвращает понятную ошибку. При успешном удалении связи/revisions/chunks удаляются транзакционно. Сценарий частичного удаления нескольких ревизий, удаление старых versions/traces и восстановление после завершения процесса во время удаления всё ещё требуют отдельного прогона; F18-04 открыт.
- Offline-поведение отдельных репозиториев описано исходниками, но полный пользовательский сценарий после отключения сети не пройден.
