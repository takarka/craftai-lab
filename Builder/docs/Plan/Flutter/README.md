# Этапы Flutter

[Общий план и требования](../flutter-implementation-plan.md) · [Другой контур](../Backend/README.md)

21 отдельный этап. Владелец — команда Flutter: UI, local-first domain/storage, API-клиенты, iOS/Android, контент приложения и мобильная поставка. Сервер передаёт готовые контракты/окружение; его реализация вынесена в B00–B09.
