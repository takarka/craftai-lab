# F15. Уровень 5 — демонстрационный MCP

[Все этапы Flutter](README.md) · [Общий план](../flutter-implementation-plan.md)

**Контур:** только Flutter, локальные данные, native-адаптеры, клиентские тесты и мобильная поставка.

**Внешний вход backend:** B05: демонстрационный MCP. Получение готового API/отчёта не является серверной работой этого этапа.

**Граница:** здесь не создавать серверные endpoints, БД, gateway, provider config или backend deployment. Если API не готов, использовать явно обозначенные contract fixtures для разработки; живую приёмку оставить заблокированной. Упоминания разделов/ADR/T-сценариев относятся к общему плану.

**Зависимость:** F14, реальный CraftAI MCP gateway.

- [x] F15-01. Реализовать S44 и binding одного рабочего коннектора «Каталог уроков CraftAI».
- [x] F15-02. Показать data disclosure и доступные capabilities; по умолчанию только чтение каталога.
- [x] F15-03. Подключать через аккаунт CraftAI без дополнительного внешнего login.
- [x] F15-04. Получать tools/list и вызывать tools/call через разрешённый gateway; не подключаться к произвольному URL по тексту модели.
- [x] F15-05. Валидировать server tools schemas и размеры результатов; возвращать понятную ошибку при несовместимости.
- [x] F15-06. Реализовать поиск урока и сохранение найденного материала в локальные заметки с отдельными разрешениями/подтверждением по политике действий.

- [x] F15-09. Проверить revoke во время ожидания подтверждения/выполнения и разрыв сети.
