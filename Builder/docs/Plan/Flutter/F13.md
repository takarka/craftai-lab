# F13. Уровень 4 — память

[Все этапы Flutter](README.md) · [Общий план](../flutter-implementation-plan.md)

**Контур:** только Flutter, локальные данные, native-адаптеры, клиентские тесты и мобильная поставка.

**Внешний вход backend:** B03 для проверки использования выбранных фактов. Получение готового API/отчёта не является серверной работой этого этапа.

**Граница:** здесь не создавать серверные endpoints, БД, gateway, provider config или backend deployment. Если API не готов, использовать явно обозначенные contract fixtures для разработки; живую приёмку оставить заблокированной. Упоминания разделов/ADR/T-сценариев относятся к общему плану.

**Зависимость:** F07/F08/F09/F10.

- [x] F13-01. Реализовать S42: добавление, изменение, выключение и удаление фактов.
- [x] F13-02. Показывать напоминание о данных учеников; не обещать автоматическое распознавание ФИО/ИИН.
- [x] F13-03. Ввести явный предложенный факт и действия «Сохранить / Нет»; предложение модели не является сохранённой памятью.
- [x] F13-04. Добавить policy выбора фактов для контекста с ограничением токенов и стабильным порядком.
- [x] F13-05. Показывать выбранные факты в trace и объяснять разницу между памятью и текущей историей разговора.
- [x] F13-06. Сохранять изменения памяти вместе с version metadata и учитывать физическое удаление в исторических снимках.
- [x] F13-07. Подготовить практику: три неперсональных факта, проверка в новом разговоре, удаление одного и повтор.
- [x] F13-08. Проверить, что отсутствие истории не отключает явно сохранённую память и наоборот.

**Приёмка:** факт сохраняется только по действию учителя; удалённый/выключенный факт не попадает в следующий запрос; рентген соответствует реально выбранным фактам.

- [x] F13-V01. S42: ввод факта, предложение сохранить/отклонить, редактирование/удаление; увеличить цели мелких иконок до 44×44.
