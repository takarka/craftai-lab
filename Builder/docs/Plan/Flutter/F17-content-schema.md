# F17. Схема редакторского контента

Статус: рабочая схема для подготовки контента. Это предложение к редакторскому утверждению; оно не объявляет язык и учебные формулировки проверенными носителем.

## Общие правила

- У каждого объекта есть постоянный `id` в `snake_case`, не зависящий от текста и языка: `course.level.01`, `course.level.01.quiz.q01`, `glossary.rag`, `faq.account.delete`, `analogy.trace.secretary`.
- `contentVersion` — версия всего согласованного набора контента в формате `major.minor.patch`. Major меняется при несовместимом изменении структуры или смысла учебного прогресса; minor — при добавлении объектов; patch — при редактуре без изменения смысла и идентификаторов.
- Текстовые поля локализуются по BCP-47 кодам `ru` и `kk`. Идентификаторы, ссылки и правила зачёта общие для языков.
- Удалённые или заменённые ID не переиспользуются. Ссылки между объектами указываются только ID, а не индексом списка или отображаемым текстом.

## Уровень курса

```json
{
  "id": "course.level.01",
  "contentVersion": "1.0.0",
  "sequence": 1,
  "locales": {
    "ru": {
      "title": "...",
      "subtitle": "...",
      "goal": "...",
      "idea": {"title": "...", "text": "...", "analogyId": "analogy.trace.secretary"},
      "practice": {"task": "...", "defaultInput": "...", "expectedOutcome": "..."},
      "underTheHood": {"concept": "...", "explanation": "...", "layers": []},
      "questions": [],
      "summary": "...",
      "reflection": null
    },
    "kk": {}
  },
  "evidence": {"type": "...", "threshold": 0.66}
}
```

Вопрос имеет `id`, локализованные `prompt`, `options`, `explanation` и необязательную `hint`; `correctOptionId` ссылается на стабильные ID вариантов ответа. Порог и тип практического свидетельства хранятся в данных курса, а не в виджете. Существующая модель использует целочисленные номера уровней и индексы правильных вариантов; переход к этой форме требует миграции и сохранения старых checkpoint.

## Глоссарий, FAQ и аналогия

- Глоссарий: `id`, `contentVersion`, `levelId`, `categoryId`, локализованные `term` и `definition`, необязательные ссылки `relatedTermIds`.
- FAQ: `id`, `contentVersion`, локализованные `question` и `answer`, `categoryId`, список связанных экранов/статей по стабильным ID. Ответ не содержит неутверждённых обещаний SLA или доступности API.
- Аналогия: `id`, `contentVersion`, локализованные `title`, `story`, `subtitle`, элементы с `id`, `lifeTerm`, `assistantTerm` и `iconName`, а также локализованный итог. Урок и trace ссылаются на один ID, чтобы не расходиться.

## Проверки при подготовке набора

Проверка должна сообщать об ошибке для дублирующихся/пустых ID, отсутствующего `ru` или `kk`, пустых обязательных полей, битых ссылок, неизвестного уровня, вопроса без допустимого правильного ответа, порога вне `(0, 1]`, уровня без практики/итога, отсутствующего свидетельства зачёта и повторного использования ID с другим назначением. Эти правила описывают цель F17-08; автоматическая проверка ещё не подключена.
