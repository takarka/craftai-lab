# F19. Настроить мобильную сборку и поставку

[Все этапы Flutter](README.md) · [Общий план](../flutter-implementation-plan.md)

**Контур:** только Flutter, локальные данные, native-адаптеры, клиентские тесты и мобильная поставка.

**Внешний вход backend:** B09: готовое окружение, стабильные URL и версия API. Получение готового API/отчёта не является серверной работой этого этапа.

**Граница:** здесь не создавать серверные endpoints, БД, gateway, provider config или backend deployment. Если API не готов, использовать явно обозначенные contract fixtures для разработки; живую приёмку оставить заблокированной. Упоминания разделов/ADR/T-сценариев относятся к общему плану.

**Зависимость:** инфраструктуру CI начать в F02; финальные задания требуют стабильного приложения.

- [ ] F19-01. Зафиксировать Flutter SDK/lockfile и воспроизводимые команды CI.
- [ ] F19-02. На каждый PR выполнять format/analyze/unit/widget/content/schema checks и доступные contract tests.
- [ ] F19-03. Собирать Android на подходящем runner; iOS — на macOS с Xcode и согласованной signing-конфигурацией.
- [ ] F19-04. Проверять embedding/runtime и все native plugins в release-сборках arm64, а не только debug-эмуляторе.
- [ ] F19-05. Завести отдельные application ID, bundle ID, display name, icons/splash и staging/prod environments.
- [ ] F19-06. Убрать `com.example.builder`, dev menus и fake adapters из production-поставки.
- [ ] F19-07. Хранить signing keys/tokens в секретах CI; не добавлять их в репозиторий/план.
- [ ] F19-08. Подготовить TestFlight/Android internal testing, changelog, app version/build numbering.
- [ ] F19-09. Заполнить privacy manifests, Data Safety/App Privacy, permission usage descriptions и app-review сценарии по фактическому поведению.
- [ ] F19-10. Проверить production URL восстановления пароля, политику конфиденциальности, поддержку и механизм жалобы.

**Приёмка:** подписанные Android/iOS-сборки устанавливаются на целевые устройства, подключаются к правильному backend и не содержат временных разрешений/секретов/имитации результатов.
