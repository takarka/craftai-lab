# F07. Реализовать разговор, историю и конвейер контекста

[Все этапы Flutter](README.md) · [Общий план](../flutter-implementation-plan.md)

**Контур:** только Flutter, локальные данные, native-адаптеры, клиентские тесты и мобильная поставка.

**Внешний вход backend:** B03: generation/continuation; B07: жалоба при включении функции. Получение готового API/отчёта не является серверной работой этого этапа.

**Граница:** здесь не создавать серверные endpoints, БД, gateway, provider config или backend deployment. Если API не готов, использовать явно обозначенные contract fixtures для разработки; живую приёмку оставить заблокированной. Упоминания разделов/ADR/T-сценариев относятся к общему плану.

**Зависимость:** F03/F05/F06; input-контракты будущих instructions/knowledge/memory/tools можно начать с пустых adapters.

- [x] F07-01. Собрать S10: шапку, empty state, подсказки по предмету, список сообщений, composer, меню нового/истории.
- [x] F07-02. Реализовать CRUD разговоров и политику хранения истории, включая режим без постоянной записи.
- [x] F07-03. Создать единый `ContextAssembler`: активная инструкция, выбранные факты, retrieval-фрагменты, доступные tools, релевантная история и запрос.
- [x] F07-04. Ограничить контекст по реальным capabilities модели; заранее резервировать место под ответ и tool-loop.
- [x] F07-05. Сохранять immutable context manifest до отправки; текущая конфигурация не меняет уже идущую генерацию.
- [x] F07-06. Реализовать streaming parser, coalescing обновлений UI, stop/cancel и partial/interrupted сообщения.
- [x] F07-07. Поддержать безопасный Markdown, источники, code blocks, copy и сохранение в заметку только при доступном инструменте.
- [x] F07-08. Реализовать offline, медленный ответ >10 секунд, сеть/сервер/контекст/категория error и явный повтор.
- [x] F07-09. При смене модели/умения добавлять понятный разделитель в текущем разговоре.
- [x] F07-10. Сохранять положение при чтении истории; не тянуть экран вниз при каждой дельте.
- [x] F07-11. Добавить путь жалобы на ответ с минимальным объёмом отправляемых данных.
- [x] F07-12. Обработать background/resume и закрытие приложения без потери уже полученного текста и без автоматического внешнего действия.

**Приёмка:** первый реальный ответ, остановка и повтор работают; потоковые дельты не дублируются; восстановленная история имеет правильные version/request IDs; late events другого владельца/epoch игнорируются.
