# Craft Builder

Мобильное приложение экосистемы CraftAI: учитель любого предмета собирает собственного ИИ-ассистента и по ходу курса (уровни 1–5 в MVP) понимает, как ИИ устроен внутри.

## Документация — `docs/`
- `craft-builder-concept.md` — концепция (v5)
- `craft-builder-design-brief.md` — ТЗ дизайнеру (v3.1)
- `functional-requirements.md` — функциональные требования (v0.2)
- `methodology.md` — методичка курса (v0.2)

## Дизайн — `design/`
Исходники макетов приложения (экспорт из Design-артефакта claude.ai): `.dc.html` — экраны 390×844 (S*, Main = S10), диалоги D01–D08, UI-кит UK1–UK4, персонаж `Char`; `canvas.json` — раскладка холста.
Файлы рендерятся только внутри Design-артефакта (нужен `support.js` рантайма), как обычные HTML-страницы они не откроются.
