# План демонстрации Craftai Lab

Документ для подготовки и проведения демонстрации MVP `0.1.0+1`. Основан на приёмочном сценарии T01 ([PRD](plans/CraftAI_Lab_PRD_Codex_Challenge.md), раздел 8) и разделе 3 [README](../README.md).

## 1. Цель и формат

| Формат | Длительность | Для чего |
| --- | --- | --- |
| Видео для конкурсного пакета | до 60 секунд | Обязательная часть итогового пакета (PRD: «презентация до двух слайдов либо видео до одной минуты») |
| Показ вживую | 5–7 минут | Защита, вопросы комиссии, подробный разбор сценария T01 |

Главная мысль демо: **учитель сам собирает управляемого ИИ-агента под предмет и класс и контролирует, что агент делает** — инструкция, материалы, подтверждение записи, трасса «Как выполнено».

## 2. Где показывать

- Веб-версия (без установки): https://takarka.github.io/craftai-lab/
- Android APK: [GitHub Release v0.1.0](https://github.com/takarka/craftai-lab/releases/tag/v0.1.0)
- Сервер: `https://craftai-lab-api.onrender.com` (Render, бесплатный тариф)

## 3. Подготовка (за 10–15 минут до записи)

- [ ] Открыть `https://craftai-lab-api.onrender.com/health` и дождаться `{"status":"healthy"}`. Сервер засыпает после 15 минут простоя, первый запрос будит его до минуты.
- [ ] Убедиться, что в настройках сервиса Render задан `CRAFTAI_OPENROUTER_API_KEY` и на балансе OpenRouter есть средства. Без ключа агент не сможет ответить.
- [ ] Не пушить в `main` перед демо: каждый пуш перезапускает сервер и **стирает все аккаунты и агентов** (база SQLite не постоянная).
- [ ] Войти тестовым аккаунтом (данные у автора, в репозиторий не записываются) или зарегистрировать новый.
- [ ] Заранее создать агента **«Естествознание 5»**:
  - предмет: «Естествознание», класс: «5»;
  - требования: «Готовь ровно три нумерованных вопроса для пятого класса. Используй учебный материал. Не добавляй ответы»;
  - нажать «Составить инструкцию», проверить текст и создать агента;
  - открыть **«Настройки агента»** и включить оба инструмента: «Сохранение материалов» и «Поиск по материалам», затем «Сохранить». **У нового агента они выключены**: без них агент может ответить «материал сохранён», ничего не сохранив.
- [ ] Помнить: агент **не видит предыдущие сообщения диалога**, каждый запрос обрабатывается отдельно. Материал и задачу писать в одном сообщении; уточнения отдельным сообщением не работают.
- [ ] Держать под рукой учебный текст для запроса:
  > Испарение — переход жидкости в газ с её поверхности. Оно происходит при разных температурах. При нагревании испарение обычно ускоряется.
- [ ] Один раз прогнать сценарий видео целиком, чтобы модель «прогрелась» и время ответа было предсказуемым.
- [ ] Запись экрана: браузер в режиме мобильной ширины (DevTools → устройство ~400 px) или Android-телефон. Отключить уведомления, закрыть лишние вкладки, увеличить масштаб шрифта при необходимости.

## 4. Сценарий видео (≤ 60 секунд)

| Время | На экране | Закадровый текст |
| --- | --- | --- |
| 0–8 с | Экран входа → **«Мои агенты»** | «Craftai Lab — приложение, в котором учитель сам собирает ИИ-агента под свой предмет и класс». |
| 8–20 с | Карточка «Естествознание 5» → **«Настройки агента»**: предмет, класс, инструкция | «Агент получает чёткую инструкцию: три вопроса для пятого класса, только по материалу, без ответов». |
| 20–35 с | Диалог (кнопка **«Диалог»** на карточке): одним сообщением «Подготовь вопросы по материалу: <текст про испарение>», отправить кнопкой-стрелкой (Enter делает перенос строки) → ответ с тремя вопросами | «Агент работает по учебному материалу учителя и соблюдает правила». |
| 35–48 с | «Сохрани этот материал с названием Испарение» → карточка подтверждения (инструмент, название) → **«Подтвердить»** | «Любая запись данных — только с явного согласия учителя». |
| 48–60 с | Кнопка **«Как выполнено»** → шаги выполнения, подтверждение, лимиты. Финальный кадр: ссылка на веб-версию | «Каждый шаг агента прозрачен. Попробуйте: takarka.github.io/craftai-lab». |

Если ответ модели идёт дольше 5 секунд — вырезать ожидание при монтаже.

## 5. Расширенный показ вживую (5–7 минут)

| № | Действие | Ожидаемый результат |
| --- | --- | --- |
| 1 | Войти, открыть **«Мои агенты»** | Список агентов, лимит 5 |
| 2 | **«Создать агента»** «Естествознание 5», задать инструкцию; в **«Настройки агента»** выбрать модель и включить инструменты материалов | Агент появился в списке, «Настройки применены» |
| 3 | Отправить текст про испарение + «Подготовь вопросы по материалу» | Ровно три нумерованных вопроса без ответов |
| 4 | Попросить сохранить фрагмент «Испарение» → **«Подтвердить»** | Материал сохранён, виден идентификатор; до подтверждения запись не происходит |
| 5 | Новый диалог: «Найди материал Испарение и подготовь вопросы» → **«Как выполнено»** | В трассе виден реальный поиск по материалам |
| 6 | **«Настройки агента»** → **«Скиллы»**: включить «Подготовка заданий», правило — два вопроса с краткими ответами; повторить запрос | Два вопроса с краткими ответами |
| 7 | Сохранить в памяти предпочтение «пятый класс», затем удалить | В новом контексте записи нет |
| 8 | Перезапустить приложение (обновить страницу) | Агент и настройки на месте |
| 9 | Создать второго агента для объяснения новой темы со второй моделью | Агент отвечает по своим правилам |
| 10 | Сбросить первого агента с подтверждением | Второй агент и прогресс курса сохранены |

Показать отказ: на шаге 4 один раз нажать **«Отклонить»** и показать в «Как выполнено», что запись не выполнена.

## 6. Запасной план

| Проблема | Что делать |
| --- | --- |
| Сервер долго не отвечает | Подождать до минуты (просыпается Render), параллельно рассказывать про архитектуру |
| Нет ответа модели (ключ, баланс, лимит) | Показать создание и настройку агентов, карточку подтверждения и «Как выполнено» на заранее выполненном запуске |
| Аккаунт пропал после перезапуска сервера | Зарегистрироваться заново (занимает ~30 с), агента создать по шагу 2 |
| Интернет недоступен | Показать заранее записанное видео из раздела 4 |
| Нужна работа без сервера | Локальный деморежим `lib/main_demo.dart` (только debug-сборка): **«Открыть» → «Открыть демодиалог»** |

## 7. Пробный прогон 16.11.2026

Локальный запуск того же кода (сервер и веб-сборка на `127.0.0.1`, модель `google/gemini-2.5-flash`).

| Проверка | Результат |
| --- | --- |
| Регистрация, создание агента, сохранение настроек, перезагрузка страницы | Работает |
| Три нумерованных вопроса без ответов | Работает после исправления шаблона инструкции (раньше фраза «Уточняй недостающие условия» заставляла агента переспрашивать) |

| История диалога | **Не реализована**: агент не видит предыдущие сообщения, в ленте только последний ответ |
