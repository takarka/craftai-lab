# Аудит безопасности CraftAI Lab

**Дата:** 25 ноября 2026 г.  
**Проверенная версия:** [`c2b78f0`](https://github.com/takarka/craftai-lab/commit/c2b78f049a6de3e42fb79b4faec49c870c9a46ab) в ветке `main`.  
**Статус:** статический аудит завершён. Исправления из этого документа ещё не внесены.

## Что проверили

Сервер FastAPI, клиент Flutter, доступ к данным агентов, обработку материалов и фото, вызовы моделей и MCP, хранение сессий, тесты и конфигурацию сборки. Учли угрозы от инструментов автоматизации атак, таких как Cairn и ARTEX: они ускоряют поиск и использование обычных слабых мест, а не требуют отдельного набора защит.

В основных путях работы с агентами и запусками сервер проверяет владельца. В обычном диалоге сервер ограничивает набор инструментов и требует подтверждения записи материала. Статический аудит не подтверждает инцидент и не доказывает отсутствие утечек или других уязвимостей. Публичный стенд не тестировали; действующие настройки Render, историю секретов и полный список известных уязвимостей зависимостей не проверяли.

## План исправлений

| Приоритет | Зона | Изменение и критерий готовности |
| --- | --- | --- |
| P1 | Вызовы моделей | Единые квоты для диалога, распознавания изображений и других вызовов. Ограничение на пользователя и на весь сервис, включая параллельные запросы. При исчерпании бюджета вызов к провайдеру не уходит. |
| P1 | Релиз iOS | Проверять параметры релиза и передавать их отдельно, без сборки строки команды из пользовательского ввода. Выдавать секреты только в защищённом окружении для разрешённых веток. Некорректный параметр блокирует запуск сборки. |
| P1 | Данные агентов и MCP | Отделять данные из материалов, памяти и истории от системных правил. В подтверждении показывать точное действие и сохраняемый текст. Внешним клиентам выдавать отдельные токены с минимальными правами и проверять права на сервере. Нужны проверки, что недоверенный материал не меняет разрешения, а отклонённое действие не выполняется. |
| P2 | Вход и файлы | Ограничить частоту запросов и размер тела до обработки; разбирать документы с отдельными лимитами времени и памяти. Слишком большие файлы отклоняются до разбора. |
| P2 | Сессии и удаление аккаунта | Сделать обновление токенов атомарным и отзывать другие сессии после смены пароля. Проверить на PostgreSQL полное удаление данных аккаунта, включая данные Lab. |
| P2 | Подтверждения | Обрабатывать решение атомарно и исключить повторную запись. Несколько одновременных запросов на подтверждение не создают несколько записей. |
| P2 | Зависимости и сборка | Собирать сервер с зафиксированными зависимостями из lock-файла, закрепить версии сборочных компонентов, добавить проверки зависимостей и утечек секретов. Убедиться, что публичное окружение не запускается с настройками для разработки. |

## Перед публичным пилотом

Закрыть P1 и прогнать проверки на отдельном стенде с тестовыми аккаунтами и без реальных данных учеников. Внешний MCP и Code Mode не открывать, пока не проверены ограниченные права, лимиты и подтверждение действий. Если проблема обнаружена до исправления, не публиковать подробности в открытых задачах и обсуждениях репозитория.
