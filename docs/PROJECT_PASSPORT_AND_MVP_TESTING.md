### 1.1. Что реализовано и что ограничено в MVP

- **Что работает в MVP (`0.1.0+1`):**
  - регистрация/авторизация и изоляция данных по владельцу (`owner_id`) и по каждому агенту (`agent_id`);
  - управление до **5 активных агентов** на аккаунт (создание через мастер или вручную, редактирование, версионирование конфигураций, копирование конфигурации без данных, сброс агента, удаление с освобождением слота);
  - серверный runtime/harness (`POST /lab/v1/agents/{id}/runs`, SSE-поток) с лимитами: до **3 вызовов инструментов**, до **60 секунд** активного выполнения, истечение подтверждения через **15 минут**, защита от повторов по `Idempotency-Key`;
  - управляемый MCP «Материалы» (`save_material`, `search_materials`) с раздельным включением сохранения и поиска и карточкой явного подтверждения записи;
  - каталог из 2 моделей (выбираются через `CRAFTAI_LAB_MODEL_*`) и 2 скиллов («Подготовка заданий», «Проверка качества»);
  - память агента (просмотр и удаление записей), загрузка текста (до 10 000 знаков) и фото (JPEG/PNG до 10 МБ с проверкой сигнатуры и извлечением текста), трасса **«Как выполнено»**;
  - 7-урочный курс и локальный шаблонный деморежим (`Builder/lib/main_demo.dart`).
- **Ограничения и особенности текущей сборки:**
  - каждый запрос в диалоге обрабатывается как отдельный контекст без сквозной истории предыдущих сообщений в одном чате — учебный материал и задачу нужно передавать в одном сообщении;
  - на бесплатном тарифе Render сервер засыпает через 15 минут простоя (первый запрос после паузы занимает до 60 секунд), а при перезапуске/деплое временная БД SQLite очищается;
  - в локальном деморежиме (`main_demo.dart`) ответы имитируются шаблонами без вызова LLM, а фото/OCR, SSE и курс в деморежим не входят;
  - для вызова реальных LLM на сервере необходим активный `CRAFTAI_OPENROUTER_API_KEY` с балансом OpenRouter;
  - в мобильных манифестах текущей сборки активны только сетевые разрешения (`INTERNET`, `ACCESS_NETWORK_STATE`); разрешения камеры/галереи в манифесты ещё не добавлены.

### 1.2. AI-инструменты, личный вклад и сторонние компоненты

- **Личный вклад автора:** постановка задачи и требований к учебному ИИ-конструктору, проектирование архитектуры мульти-агентности (5 изолированных агентов), удаление лишних модулей (календарь, расписания, генерация DOCX/PDF), проектирование серверного контракта `/lab/v1`, клиентского экрана «Мои агенты» и деморежима, код-ревью и приёмочное тестирование.
- **Использованные AI-инструменты:** Claude Code (модели Claude Sonnet 5.5 и Claude Opus 5.5) для генерации и рефакторинга кода Flutter-клиента и backend, написания автотестов, подготовки документации и релизной сборки (соавторство отражено в `Co-Authored-By` в коммитах).
- **Сторонние компоненты и лицензии:** открытые пакеты Flutter (`Builder/pubspec.yaml`) и Python (`backend/pyproject.toml`), шрифты `Onest` и `JetBrains Mono` (лицензия SIL OFL). Лицензия самого репозитория не задана (`publish_to: 'none'`).
- **Статус автотестов на момент сдачи:** `pytest` — 37 passed; `flutter analyze` — 0 issues; интеграционный тест приёмки `Builder/integration_test/t01_mvp_acceptance_test.dart` и автотесты фаз LM00–LM07 добавлены в репозиторий. Сквозная ручная проверка финального сдаваемого MVP на целевом устройстве (`Redmi Note 9 Pro`, Android 10) зафиксирована как требующая проведения по заданию ниже.

## Часть 2. Задание для тестирования MVP

### 2.1. Цель и объект тестирования

**Цель:** проверить работоспособность сдаваемого MVP `CraftAI Lab` (`0.1.0+1`) в реальных условиях с точки зрения независимого проверяющего (без помощи автора), подтвердить выполнение основного пользовательского сценария (T01) и ключевых нефункциональных/защитных ограничений (T02–T09).

**Варианты среды для тестирования (выберите один основной):**
1. **Веб-версия (быстрая проверка без установки):** `https://takarka.github.io/craftai-lab/` (желательно открыть в Chrome в режиме мобильной ширины ~400 px или с телефона).
2. **Android-устройство:** скачать и установить [craftai-lab-0.1.0-arm64.apk](https://github.com/takarka/craftai-lab/releases/download/v0.1.0/craftai-lab-0.1.0-arm64.apk) из GitHub Release `v0.1.0`.
3. **Локальный деморежим без сервера и API-ключей (резервный вариант для разработчика):** запуск `flutter run -t lib/main_demo.dart -d chrome --web-hostname 127.0.0.1 --web-port 8080` из каталога `Builder/` (проверяется только UI и шаблонный сценарий подтверждения).

### 2.2. Подготовка перед началом теста

1. **Пробудить сервер:** открыть `https://craftai-lab-api.onrender.com/health` и дождаться ответа `{"status":"healthy"}` (при простое более 15 минут пробуждение может занять до 1 минуты).
2. **Регистрация:** запустить приложение, зарегистрировать новый аккаунт с любым синтетическим email и паролем (подтверждение почты не требуется; реальные персональные данные не вводить). Пройти стартовый онбординг, если он отобразится.
3. **Подготовить синтетический учебный текст:**
   > Испарение — переход жидкости в газ с её поверхности. Оно происходит при разных температурах. При нагревании испарение обычно ускоряется.
4. **Важные правила работы с MVP, которые нужно учитывать при тесте:**
   - У нового агента инструменты **«Сохранение материалов»** и **«Поиск по материалам»** по умолчанию **выключены** — их нужно включить в настройках агента.
   - Агент не хранит историю предыдущих сообщений в текущем диалоге — учебный текст и задание нужно отправлять **одним сообщением** (кнопка-стрелка отправляет сообщение, `Enter` переносит строку).

### 2.3. Основное задание: сквозной сценарий (T01)

Выполните шаги последовательно и зафиксируйте фактический результат в протоколе (раздел 2.5).

| Шаг | Действие тестировщика | Ожидаемый результат |

Выбрать задачу «Подготовка заданий», имя **«Естествознание 5»**, предмет **«Естествознание»**, класс **«5»**. Задать требование: *«Готовь ровно три нумерованных вопроса для пятого класса. Используй учебный материал. Не добавляй ответы»*. Нажать **«Составить инструкцию»** и создать агента. | Агент «Естествознание 5» появился в списке «Мои агенты», счётчик слотов увеличился на 1. |
| **2. Настройка инструментов** | Открыть **«Настройки агента»**, проверить выбранную модель, включить оба инструмента: **«Сохранение материалов»** и **«Поиск по материалам»**, нажать **«Сохранить»**. | Появилось подтверждение сохранения («Настройки применены»). |

| **6. Скиллы** | Перейти в **«Настройки агента» → «Скиллы»**, включить скилл **«Подготовка заданий»**, изменить допустимое правило на выдачу **двух вопросов с краткими ответами**, сохранить и повторить запрос по материалу «Испарение». | Агент формирует 2 вопроса с краткими ответами в соответствии с обновлённым правилом скилла. |

| **8. Второй агент (перенос)** | Создать второго агента без использования пошагового мастера (для объяснения новой темы), выбрать **вторую модель** из каталога, задать собственные правила и отправить проверочный запрос. | В списке 2 изолированных агента; второй агент отвечает по своим правилам с использованием второй модели. |
| **9. Сброс агента** | Выбрать первого агента («Естествознание 5») и выполнить **«Сбросить»** с подтверждением в диалоге. | Настройки/память/материалы первого агента очищены; второй агент и прогресс курса (если открывался) **не затронуты**. |
